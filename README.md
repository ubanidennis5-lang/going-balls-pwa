# Going Balls — 3D PWA Clone

A 3D rolling ball platformer built completely in HTML5, CSS, and JavaScript. Uses **Three.js** for rendering and **Cannon-es** for rigid body physics.

This project is packaged as a **Progressive Web App (PWA)**, making it ready to be converted into an Android App Bundle (`.aab`) using Microsoft's PWABuilder.

## How to Play
1. **Drag Up/Down**: Accelerate forward or brake.
2. **Drag Left/Right**: Steer the ball to avoid falling off the track.
3. Collect coins and reach the furthest distance possible.

## Tech Stack
- **Graphics**: Three.js (WebGL)
- **Physics**: Cannon-es (Rigid body physics)
- **Deployment**: PWA + GitHub Pages
